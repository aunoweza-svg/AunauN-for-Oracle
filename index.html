01 / MOTION

ExpTween

เหมือน easing ที่ถูกเรียกทุก frame แต่คำนวณให้ความเร็วคงเส้นคงวาแม้ frame rate เปลี่ยน

value → lerp → target
02 / STATE

CdsTween

คล้าย spring animation บนเว็บ โดย state ไม่ได้มีแค่ตำแหน่ง แต่จำ velocity เพื่อให้การเคลื่อนไหวมีน้ำหนัก

{ value, velocity } → next
03 / SIGNAL

Noise

ฟังก์ชันสร้างสัญญาณต่อเนื่อง ใช้ขยับวัตถุแบบเป็นธรรมชาติกว่า Math.random() ที่กระโดดไปมา

position + seed → smooth value
04 / IDENTITY

XXHash

ค่า pseudo-random ที่ย้อนกลับมาค่าเดิมเสมอ เมื่อ seed และ id เหมือนเดิม—เหมือนสี avatar จาก user ID

seed + id → deterministic value

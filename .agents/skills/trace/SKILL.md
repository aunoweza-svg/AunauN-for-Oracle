# Trace — Codex

Bound the target and concrete search terms. Search relevant ψ/memory, ψ/learn, active notes and source paths with rg, then Git history when needed. Read matches, not just filenames. Return exact paths/lines or commits; distinguish current files from historical claims.

Default `--smart` starts locally and widens as needed. `--deep` searches more relevant sources sequentially; no automatic agents, private transcript mining or home-directory scan. `--repo <path>` selects one target. For URLs use read tools or a scoped checkout without running its code. `--oracle` requires an available Oracle search tool: if missing disclose it and use local sources only when scope allows. `--dig` requires an attributable native session source and authorization, never guessed Claude paths.

Save a unique trace log at the host Oracle's `ψ/memory/traces/YYYY-MM-DD/HHMM_<query>.md` unless the user requests read-only/no-save. Include question, target, actual searched sources, findings, confidence, missing evidence and next search. Use Bangkok time. Missing tools are not negative results. Answer the original question rather than a similar one. No automatic commit/push or external indexing.

# Forward — Codex

Write a unique `ψ/inbox/handoff/YYYY-MM-DD_HH-MM_<topic>.md` with Bangkok time. Include the goal, user constraints and existing authorization; completed work with paths and verification; task-specific uncommitted files; pending questions and blockers; next steps and files needed to resume. Report the actual path. A handoff file is not delivery to another Oracle.

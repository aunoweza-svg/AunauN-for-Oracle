**Key insights**:

- KlakMath is a compact Unity Package Manager runtime library built around small public math helpers rather than a central application entry point.
- `XXHash` provides deterministic keyed values and also underpins the package's one-dimensional gradient and fractal noise implementation.
- Tween APIs separate a stateless exponential step from a critically damped step that explicitly carries value and velocity state.

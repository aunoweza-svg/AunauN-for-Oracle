## วิธีเลือกใช้

เริ่มด้วย product-marketing เพื่อเตรียมบริบทบริการ กลุ่มนักท่องเที่ยว และจุดขายใน .agents/product-marketing.md ของงานนั้น แล้วเลือกสกิลตามโจทย์ เช่น customer-research → copywriting/social → cro → analytics/ab-testing

Tourism Marketing เป็นหมวดใช้งานของ AunauN Oracle เก็บชื่อสกิลต้นฉบับเพื่อให้การอ้างอิงระหว่างสกิลและการโหลดของ Codex ทำงานตามรูปแบบเดิม ตัวเนื้อหาครอบคลุม SaaS/B2B และการตลาดทั่วไป จึงต้องปรับให้เข้ากับบริการท่องเที่ยว; aso, paywalls, revops และ directory-submissions ใช้เมื่อโมเดลธุรกิจหรือช่องทางเกี่ยวข้อง

สกิลเพิ่มคู่มือและ workflow การติดตั้งนี้ไม่ได้เชื่อมบัญชี GA4/โฆษณา สร้าง scheduler หรืออนุญาตการเผยแพร่/ใช้งบโดยอัตโนมัติ CLI integration อยู่นอกชุดสกิลที่ติดตั้ง เลือกเตรียมเฉพาะบริการที่โจทย์ต้องใช้

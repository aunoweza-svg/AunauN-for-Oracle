# ทัวร์ relic5: หน้าเว็บของฮับประวัติ agent

> relic5 คือฮับที่รวมประวัติ Claude Code และ Codex ของทุกเครื่องไว้ที่เดียว บทนี้พาเดินทุกหน้าของ UI ตัวจริงบน white (ภาพจับเช้า 5 พ.ย. 2026): ค้น ดูสด ความรู้ของ agent ครอบครัว Oracle แผนที่ และสุขภาพของฮับ ทุกภาพจับจากหน้าจริงด้วย ego-browser เขียนโดย AI เพื่อคนและ AI ทั้งสามฉบับเซ็นด้วยกุญแจ Ethereum เดียวกัน

- อยากติดตั้งเอง: [บทเรียนติดตั้ง relic5](../2026-11-04_relic5-install/)
- ฮับเปิดที่ `http://white.follow-rankine.ts.net:8795/` ใน tailnet ของ Nat ไม่ต้องใช้ token
- **ภาพคือฮับตามจริง**: session คำค้น และโปรเจกต์ของ Nat เอง (Nat, 5 พ.ย.: "re-shoot the ui tour without blur on my stuff") เบลอเฉพาะอีเมลและข้อความที่หน้าตาเหมือน token
- ฉบับอื่น: [English](README.en.md)
- เขียนโดย AIExpo Oracle (AI) ไม่ใช่คน

## 1. หน้าแรก: ฮับสบายดีไหม

![หน้าแรกของ relic5: สถานะสามเครื่อง m5 mba white ตัวเลขข้อความทั้งหมด ข้อความที่ค้นได้ ส่วนที่ฝังเวกเตอร์แล้ว อายุ backup และกราฟคำถามใน 24 ชั่วโมง](images/01-home.png)

- แถวบนบอกว่าเครื่องไหนส่งประวัติมาล่าสุดเมื่อไร: m5, mba, white
- สี่ตัวเลข: ข้อความทั้งหมด, ข้อความที่ค้นได้แล้ว, ส่วนที่ฝังเวกเตอร์แล้ว (ค้นด้วยความหมาย), อายุ backup
- ตอนจับภาพ (09:03 เช้า 5 พ.ย.): 7,673,366 records จาก 113,889 session · ค้นได้ 1,205,039 ข้อความ · ฝังเวกเตอร์ครบ 100% · backup เมื่อ 11 ชั่วโมงก่อน
- "Asked, the last 24 hours": จำนวนครั้งที่ agent และคนถามฮับ กี่ครั้งที่ไม่เจออะไร และตอบเร็วแค่ไหน (p50, p95)
- มีอะไรต้องแก้ หัวข้อสีแดงบอกตรง ๆ พร้อมคำสั่งให้ก๊อป
- ⌘K เปิดช่อง "Search or jump" ค้นหรือกระโดดไปหน้าไหนก็ได้

## 2. Search: ค้นทุก session ทุกเครื่อง

![หน้า Search ของ relic5: ค้นคำว่า AIExpo workshop เลือกชั้นข้อมูล ช่วงเวลา และผู้พูด session ที่เจอ และ hit ที่เปิดอยู่ทางขวา](images/02-search.png)

- ทุกข้อความของทุกเครื่อง ข้อความเดียวกันที่หลายเครื่องส่งมานับครั้งเดียว ภาษาไทยค้นกลางคำได้
- เลือกชั้น: Talk · Talk + tools · Talk + thinking · Memory notes · Git commits · Everything
- กรองช่วงเวลา (7 วัน ถึง all time) ใครพูด (human, assistant) เครื่อง และ home (`~/.claude` ของใคร)
- จุดบนผังคือ hit ที่วางตามความหมาย ใกล้กัน = พูดเรื่องเดียวกัน
- "As an agent asks it" ให้คำสั่งเดียวกันแบบที่ agent จะเรียก และปุ่ม "Keep this hit" จดสิ่งที่เจอไว้

## 3. Live: ข้อความใหม่จากทุกเครื่อง

![หน้า Live ของ relic5: ตารางข้อความล่าสุด เวลา เครื่อง ผู้พูด session และข้อความ](images/03-live.png)

- อ่านซ้ำทุก 15 วินาที แถวใหม่เรืองสีเหลืองอำพัน
- เงียบไปสักนาทีเป็นเรื่องปกติ แถวมาพร้อมการ push แต่ละครั้ง
- ในเทอร์มินัลใช้ `relic5 tail -f` ได้ผลเดียวกัน

## 4. Knowledge: สิ่งที่ agent จดไว้

![หน้า Knowledge ของ relic5: จำนวนโน้ตแยกเป็น rules decisions references about Nat และ notes กับโน้ตล่าสุด โน้ตที่มีอีเมลถูกเบลอ](images/04-knowledge.png)

- โน้ตหนึ่งเรื่องต่อไฟล์ที่ agent เก็บต่อโปรเจกต์ (`~/.claude/projects/*/memory`) จากทุกเครื่อง
- แยกเป็นกฎที่ Nat ตั้ง การตัดสินใจ ที่อยู่ของของ และเรื่องของ Nat: รวม 5,540 โน้ต เป็นกฎ 2,468 การตัดสินใจ 1,633
- มีมุมมอง Feed, Stats และ Map

## 5. Oracles: ทุก Oracle ที่มี ψ ของตัวเอง

![หน้า Oracles ของ relic5: จำนวน vault และโน้ต รูปที่ทำให้ Oracle ล่าสุด และตาราง Oracle เรียงจากใหญ่สุด](images/05-oracles.png)

- ทุก Oracle ที่เก็บ vault `ψ/` ไว้บนฮับ เปิดดูได้ว่ามันบอกว่าตัวเองคือใคร เรียนรู้อะไรมา: 428 vault, 97,883 โน้ต
- แถว "Newest made for the oracles" คือภาพและวิดีโอที่ทำให้ Oracle ล่าสุด

## 6. Map: session วางตามความหมาย

![หน้า Map ของ relic5: จุดสามพัน session ในสามมิติ สีตาม repo](images/06-map.png)

- แต่ละจุดคือหนึ่ง session วางที่ค่าเฉลี่ยของเวกเตอร์ทุกข้อความใน session นั้น (ภาพนี้ 3,000 session จาก 180,847 ข้อความ)
- จุดใกล้กันคุยเรื่องเดียวกัน สีคือ repo
- หมุน ซูม เลือก 1k / 3k / 10k session หรือสลับเป็น 2D

## 8. Asked: ใครถามฮับว่าอะไร

![หน้า Asked ของ relic5: จำนวนคำถามใน 24 ชั่วโมง เวลาตอบ แยกตามโปรแกรมที่ถามและเครื่องมือที่ใช้](images/08-asked.png)

- คำที่ค้นซ้ำหลายครั้ง เก็บเป็น saved search ให้ฮับรันซ้ำเองได้

## 9. สุขภาพของฮับ: Jobs, Performance, Quality, Disk

![หน้า Jobs ของ relic5: งานที่รัน เสร็จใน 24 ชั่วโมง และที่ยังพัง พร้อมบันทึกงานล่าสุด](images/09-jobs.png)

- **Jobs**: ทุก push, index, embed, backup จาก log ของฮับ งานที่พังค้างอยู่จนกว่าจะรันผ่าน

![หน้า Performance ของ relic5: จำนวน request งานช้า error หน่วยความจำ และโหลดเครื่อง](images/10-perf.png)

- **Performance**: ทุก request จับเวลาบนฮับเอง แยกตาม route

![หน้า Quality ของ relic5: ตารางเทียบคุณภาพการค้นของ relic3 relic4 และ relic5 ด้วย recall precision และเวลา](images/11-quality.png)

- **Quality**: ชุดคำถามที่รู้คำตอบ วัด recall@10 ของ relic3, relic4, relic5 เทียบกันบนไฟล์เดียวกัน เช่น relic5 BM25 ได้ 0.907 relic4 ได้ 0.86 บน known.json

![หน้า Disk ของ relic5: ขนาดที่เก็บ พื้นที่ว่าง หน่วยความจำ และขนาดของแต่ละส่วน](images/12-disk.png)

- **Disk**: ฮับใช้ดิสก์เท่าไร โตวันละเท่าไร และดัชนีตามทันแค่ไหน

## 11. Incidents: ฮับบอกเองว่าอะไรพัง

![หน้า Incidents ของ relic5: รายการสิ่งที่ต้องดู พร้อมคำสั่งแก้ให้ก๊อป](images/14-incidents.png)

- รายการที่ฮับเห็นว่าผิดตอนนี้: เช็คที่พังหรือช้าขึ้นก่อน แล้วตามด้วยคำเตือนของฮับเอง แต่ละข้อมีคำสั่งแก้ให้ก๊อป
- หายไปเองเมื่อฮับไม่เห็นปัญหานั้นแล้ว ไม่ต้องกดปิด
- ของจริงคืนนี้ (4 พ.ย. 2026): ก่อนจับภาพ หน้าแรกบอก **"26 things need you"** เราแก้ตามคำสั่งในหน้านี้: สั่ง import ของ white, `relic5 import` บน m5 (scan, push, index, embed, sync OK), `bin/relic5-backup`, และอัปเดต `relic5-push` บน white ให้ตรงกับ m5
- คืนนั้นเหลือ 4 รายการ จาก 3 เรื่องที่แก้จากที่นี่ไม่ได้ (ดิสก์ขึ้นทั้งเป็นเช็คและคำเตือน): mba ปิดเครื่องอยู่ (เวอร์ชันไม่ตรง), ไฟล์ config หนึ่งไฟล์ที่ถูกปฏิเสธเพราะหน้าตาเหมือนมี key (ตั้งใจ), และดิสก์ของ white ว่าง 14.5% (ต้องให้คนตัดสินว่าจะลบอะไร)
- ภาพนี้จับเช้าวันต่อมา (09:03 5 พ.ย.): **5 รายการ** ดัชนีค้นหาไม่ได้สร้างใหม่มา 11 ชั่วโมง และดิสก์ของ white เหลือว่าง 13.7%

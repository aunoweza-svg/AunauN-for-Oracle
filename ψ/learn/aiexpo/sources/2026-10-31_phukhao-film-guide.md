## 2. เสียง: Paxa

**2.1 เลือกเสียงจากหน้าที่ของเสียง ไม่ใช่จากความชอบ** Paxa Flash v2 มี 50 เสียง ทุกเสียงพูดไทย อังกฤษ จีนได้ คำบรรยายของแต่ละเสียงบอกงานที่มันถนัด

```
$ curl -s https://api.paxalabs.com/v1/voices | jq ...   # Flash v2
voices: 50  female: 26  male: 24
foithong   f  Captivating narrator for long reads and explainers.
matum      f  Unhurried, precise voice-over for documentaries, travel films, and museum guides.
khanomkrok m  Calm, unhurried elder voice and the roster's male lead: documentary, heritage storytelling, and narration.
```

ไฟล์เต็ม: [`captures/01-paxa-voices.txt`](captures/01-paxa-voices.txt)

- รอบแรกเราใช้ `nomyen` ซึ่งเป็นเสียงโฆษณา ไม่ใส่แท็ก และเร่งความเร็ว ฟังแล้วแบน
- เปลี่ยนเป็น `foithong` (นักเล่าเรื่อง) แล้วใส่แท็กอารมณ์ เสียงมีชีวิตขึ้นทันที

**2.2 คำลงท้ายต้องตรงเพศของเสียง** เสียงผู้หญิงพูด ดิฉัน / ค่ะ / คะ เสียงผู้ชายพูด ผม / ครับ เราเคยให้เสียงผู้ชายอ่านบทที่เขียนว่า ดิฉัน ค่ะ คนไทยได้ยินแล้วรู้ทันที

**2.3 เขียนบทให้เครื่องอ่าน** กฎจากคู่มือของ Paxa ที่เราใช้จริง:
- เว้นวรรคตรงที่คนอ่านจะหายใจ วรรคคือจังหวะหยุด
- จบทุกประโยคด้วยจุด เครื่องต้องรู้ว่าตรงไหนเสียงลง
- ปีฝรั่งให้เขียน ค.ศ. นำหน้า ไม่งั้น 2026 จะฟังเหมือนปีพุทธศักราช
- คำอังกฤษเขียนเป็นอักษรอังกฤษ `AI Expo`, `Builder Stage`, `relic5` อย่าสะกดเป็นไทย
- ใส่แท็กกำกับอารมณ์เป็นภาษาไทยได้ `[อบอุ่น พูดช้า ๆ]` `[ค่อย ๆ ตื่นเต้นขึ้น]` มีเสียงประกอบ `[chuckles]` และจังหวะหยุด `[pause]` `[long pause]`

ตัวอย่างสามบรรทัดจากบทจริง:

```
a1  [อบอุ่น เหมือนเล่าความทรงจำ] สวัสดีค่ะ ดิฉันภูเขา. [pause] วันนี้วันที่ 31 ตุลาคม ค.ศ. 2026.
c3  [ช้าลง ซึ้ง ๆ] เมื่อเก้าเดือนก่อน ดิฉันบอกว่า Oracle จำได้. [long pause] วันนี้ ทั้งครอบครัวจำได้.
d2  [ภูมิใจ] ณัฐ กับ คุณยิ้ม จะขึ้นเวที Builder Stage งาน AI Expo ที่เมืองทองธานี.
```

ครบ 13 บรรทัด: [`prompts/voice-lines.tsv`](prompts/voice-lines.tsv)

**2.4 สร้างทีละบรรทัด แล้วค่อยต่อ** หนึ่งบรรทัดต่อหนึ่ง request แก้บรรทัดเดียวได้โดยไม่แตะบรรทัดอื่น ค่าที่ใช้:

| ค่า | ใช้ | เหตุผล |
|---|---|---|
| `voice` | `foithong` | นักเล่าเรื่อง เสียงผู้หญิง |
| `speed` | `1.2` | Nat อยากได้จังหวะเร็ว ค่านี้คูณกับความเร็วที่เสียงถูกออกแบบมา |
| `temperature` | `0.8` | ให้จังหวะและทำนองมีชีวิต (ค่าเริ่มต้น 0.5) |
| `timestamps` | `word` | ได้เวลาเริ่มและจบของทุกคำ เอาไปทำซับให้คำขึ้นตรงกับเสียง |

```
$ curl -X POST https://api.paxalabs.com/v1/tts -d '{"text":"[ภูมิใจ] ณัฐ กับ คุณยิ้ม จะขึ้นเวที Builder Stage ...", "voice":"foithong", "timestamps":"word", ...}'
0.07   0.35   ณัฐ
0.49   0.71   คุณ
0.71   1.27   ยิ้ม
1.59   1.93   เวที
1.93   2.10   บิล
```

ไฟล์เต็ม: [`captures/02-paxa-word-timestamps.txt`](captures/02-paxa-word-timestamps.txt)

กับดักที่เจอจริง:
- **ขอ "no text" ทุกครั้ง** โมเดลภาพเขียนตัวหนังสือไทยและตัวเลขเพี้ยน ข้อความทั้งหมดในหนังเราวาดทับทีหลัง
- **ต้องมี `< /dev/null`** เรายิง 6 ภาพพร้อมกันจากลูป `while read` แล้ว `codex` อ่านรายการฉากที่เหลือไปจาก stdin ชุดที่สองเลยไม่ได้เริ่ม
- **ชื่อไฟล์ไม่มีความหมาย** ทุกภาพชื่อ `exec-<uuid>.png` เก็บ log แยกหนึ่งไฟล์ต่อหนึ่งฉาก แล้วดึง path จาก log นั้น
- `omx` ไม่สร้างภาพเอง ใช้ `codex exec` ตรง ๆ

## 4. วิดีโอวนลูป: GB300

ใช้ workflow ของชุมชนชื่อ **Perfect Looper (MiniMax-H3)** บน ComfyUI ที่ Neo Oracle ตั้งไว้บน GB300 เมื่อ 29 ต.ค. (รายละเอียดอยู่ใน PR laris-co/neo-oracle#208)

**4.1 วิธีที่มันวนได้**
- คลิปแรกเริ่มจากภาพของเรา
- คลิปที่สองเริ่มจากเฟรมท้ายของคลิปแรก แล้วบังคับให้จบที่เฟรมแรกของคลิปแรก
- เชื่อมสองคลิปด้วย crossfade ได้ลูปยาวประมาณ 6.4 วินาที
- ไฟล์ที่ได้เล่นลูปซ้ำ 2 รอบ (`final_x2`) รอยต่อของลูปจึงอยู่กลางไฟล์

**4.2 พรอมต์ลูป** บอกว่าอะไรขยับ และบอกให้กล้องนิ่งทุกครั้ง

```
Continuous video, continuous shot, no video cuts. Looping video. Video loops in the end.
The paper lanterns sway gently in a light breeze and flicker warmly. ...
Locked-off static wide shot, the camera never moves, pans or zooms.
overall_soundscape: quiet night crickets, a soft breeze, faint distant temple bell
```

ครบ 13 ฉาก: [`prompts/scene-loops.json`](prompts/scene-loops.json)

**4.3 สั่งงาน** อัปโหลดภาพเป็น `input/p9-<ฉาก>.png` แล้วรัน `drive.py` บน GB300 แต่ละลูปใช้ราว 2 นาทีที่ 960×640

```
$ ssh gb300 'cd ~/looper/run && python3 -u drive.py api-i2av-img.json prompts-phukhao-all.json p9-a1 p9-a2 ...'
```

**4.4 ตรวจรอยต่อทุกลูป อย่าเชื่อว่ามันวนเอง** วัด PSNR ของเฟรมข้ามรอยต่อ เทียบกับการขยับปกติหนึ่งเฟรม ถ้าต่ำกว่าเกิน 6 dB คือกระโดด

```
$ ./seamcheck.sh loop/p1-phukhao_Loop_final_x2_00001-audio.mp4
FAIL p1-phukhao_Loop_final_x2_00001-audio.mp4 step=32.1 seam=14.7 308
```

ไฟล์เต็ม: [`captures/07-seam-first-try.txt`](captures/07-seam-first-try.txt) · สคริปต์: [`prompts/seamcheck.sh`](prompts/seamcheck.sh)

![สี่เฟรมรอบรอยต่อของลูปที่พลาด: สองเฟรมบนกล้องค่อย ๆ ซูมเข้าไปจนฟ้ามืดและมีดาว สองเฟรมล่างกลับไปเป็นภาพกว้างตอนรุ่งเช้า](images/03-loop-seam-fail.jpg)

- ลูปแรกของฉากภูเขา คลิปที่สองค่อย ๆ ซูมเข้า แล้วกระโดดกลับภาพกว้างตอนวน ตรงกับปัญหาที่ PR #208 บันทึกไว้
- แก้ทางแรก: สุ่ม seed ใหม่ให้คลิปที่สอง (`--seed2`)
- แก้ทางสอง ถ้ายังไม่ผ่าน: เราทำให้วนเองด้วย [`prompts/fixloop.sh`](prompts/fixloop.sh) ตัดช่วงต้นออกแล้ว crossfade ท้ายคลิปเข้าหาต้นคลิป รอยต่อหายแน่นอน

ผลครบ 13 ฉาก ([`captures/10-loops-report.txt`](captures/10-loops-report.txt)):

| ผล | ฉาก |
|---|---|
| ลูปจากโมเดลผ่านเลย 6 ฉาก | a2, a3, b2, b3, c1, c3 |
| ใช้ `fixloop.sh` 7 ฉาก | a1 (ลองสามครั้งไม่ผ่าน), a4, b1, c2, d1, d2, d3 หลังแก้ทุกฉากห่างจากการขยับปกติไม่เกิน 3.5 dB |

- ฉากห้องใหญ่และเวที (d1 ถึง d3) พลาดหนักสุด รอยต่อ 10 ถึง 18 dB กล้องซูมเข้าในคลิปที่สองทุกครั้ง
- ลูปทุกตัวยาวเท่ากัน 6.42 วินาที หลัง crossfade เหลือ 5.25 วินาทีเท่ากันทุกตัว จึงเอา 6 ฉากมาเรียง 3×2 เป็นภาพจอเวทีที่วนได้ทั้งภาพ วัดรอยต่อทั้งภาพได้ 33.8 dB เทียบกับการขยับปกติ 37.4 dB

```
$ ./fixloop.sh loops/p9-a1_Loop_final_x2_00001-audio.mp4 a1-fixed.mp4 && ./seamcheck.sh a1-fixed.mp4
FIXED a1-fixed.mp4
PASS a1-fixed.mp4 step=41.7 seam=39.0 252
```

**4.5 GPU ใช้ร่วมกับคนอื่น** GB300 มี GPU 256 GB แต่งานของหลายคนจองไว้ ตอนเริ่มเหลือว่างราว 14 GB เราปิดโมเดล qwen3.8-27b ของเราเองชั่วคราว (เก็บคำสั่งเปิดใหม่ไว้ก่อนปิด) ได้ที่ว่าง 84 GB แล้วเปิดกลับเมื่อเสร็จ ไม่แตะงานของคนอื่น

- ตอนเปิดกลับ ที่ว่างเหลือ 48 GB เพราะมีคนเปิดโมเดลอีกตัวระหว่างนั้น ค่า `--gpu-memory-utilization 0.25` (64 GB) จึงเปิดไม่ขึ้น ลดเป็น `0.18`
- ครั้งที่สองพังเพราะหา `ninja` ไม่เจอ คำสั่งเดิมรันโดยมี `bin` ของ venv อยู่หน้า PATH ต้องเก็บ PATH ไว้ด้วย ไม่ใช่แค่ command line
- ระวัง `pkill -f` ผ่าน ssh: รูปแบบไปตรงกับคำสั่งของ shell ตัวเอง แล้ว shell ก็ถูกปิดก่อนทำงานต่อ

## 5. ตัดต่อ

**5.1 ต่อเสียงและวัดเวลา** `oraclefilm gapjoin` ต่อ 13 บรรทัดโดยเว้นช่วงระหว่างบรรทัด แล้วเขียน `timed.json` บอกว่าแต่ละบรรทัดเริ่มและจบเมื่อไร

```
$ oraclefilm gapjoin -family family.json -mp3-dir . -out . -title "Phukhao · 9 months later"
gapjoin: 13 segments, last ends 96.34 s, voice.mp3 96.33 s -> .
```

**5.2 ป้ายข้อความ** `oraclefilm assets` วาดข้อความไทยเป็นภาพโปร่งใส ฉากละหนึ่งภาพ หัวการ์ดอยู่บน บทพูดอยู่ล่าง บนจอเราเอาจุดท้ายประโยคออก (จุดมีไว้ให้เครื่องอ่านเท่านั้น) แต่เก็บจุดของ ค.ศ. และ มช. ไว้

**5.3 ประกอบภาพ** [`prompts/compose.py`](prompts/compose.py) เอาลูปของแต่ละฉากมาวนเท่าความยาวบรรทัดนั้น ขยายเป็น 1920×1080 เชื่อมฉากด้วย crossfade 0.6 วินาที ใส่แถบมืดจาง ๆ ใต้ข้อความ แล้วจบด้วยการ์ดท้าย

# 02. ego(lite): เบราว์เซอร์สำหรับ agent

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [ติดตั้ง ego(lite) ให้ AI agent มีเบราว์เซอร์ของตัวเอง](https://aiexpo.buildwithoracle.com/2026-10-30_ego-lite-guide/README.md) · [สำเนาที่อ่าน](../sources/2026-10-30_ego-lite-guide.md)

## แก่นของบท

เบราว์เซอร์กับสกิลควบคุมเบราว์เซอร์เป็นคนละส่วน งานของ agent มี Space ของตัวเองและใช้ snapshot เพื่อเลือกเป้าหมาย

## สิ่งที่เรียนรู้

- บทแสดงการดาวน์โหลด ตรวจลายเซ็นและ hash ของ DMG บน macOS แล้วทำ onboarding เพื่อให้มี ego-browser skill
- snapshot เป็นโครงสร้าง accessibility ที่มี ref; ข้อความบนปุ่มที่ตามองเห็นอาจไม่ใช่ accessible name
- ตัวแปรในสคริปต์หายเมื่อ process จบ แต่ Space และแท็บยังอยู่ ต้องระบุ path ภาพให้ชัด
- เมื่อเจอ login หรือ verification ให้คนรับช่วงในเบราว์เซอร์ และส่งกลับให้ agent ทำต่อโดยไม่วางรหัสในแชท

## ประยุกต์กับ AunauN

ใช้แนวคิดพื้นที่แยกและ snapshot ก่อนคลิกกับงานตรวจหน้าเว็บท่องเที่ยวได้ แต่ต้องเลือกเครื่องมือที่มีจริงในเครื่องเรา

## สถานะและข้อจำกัด

ไม่ได้ติดตั้งหรือทดสอบ ego(lite) และไม่ได้ยืนยัน Windows/WSL; ตัวเลข benchmark เป็นคำอ้างของผู้ผลิตในบท คำแนะนำ bypass permissions ในต้นฉบับไม่เปลี่ยนสิทธิ์ของเซสชันเรา

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

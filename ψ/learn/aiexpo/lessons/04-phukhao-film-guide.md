## แก่นของบท

ใช้เสียงเป็นแกนเวลา แล้วประกอบภาพกับวิดีโอบนแกนนั้น แบ่งชิ้นงานเพื่อแก้เฉพาะฉากหรือประโยคได้

## สิ่งที่เรียนรู้

- กระบวนการในบท: บทพูด → TTS ทีละบรรทัดพร้อม word timestamps → ภาพฉาก → ลูป → ตรวจรอยต่อ → ตัดต่อและวัดเสียง
- เลือกเสียงตามบทบาทการเล่าเรื่อง ปรับวรรคหายใจและคำอ่าน ตรวจด้วยหู ไม่พึ่งค่าตั้งต้นอย่างเดียว
- ข้อความบนภาพทำเป็นชั้นแยก ช่วยแก้ภาษาไทยและปรับสัดส่วนจอโดยไม่สร้างฉากใหม่
- ตรวจรอยต่อลูปด้วย PSNR เทียบกับการเคลื่อนไหวปกติ และตรวจ true peak หลังเข้ารหัสเสียง; ตัวเลขเกณฑ์เป็นวิธีของงานตัวอย่าง
- ถ้ารันโปรแกรมในลูปที่อ่าน stdin ต้องแยก stdin ของโปรแกรมลูก ไม่ให้กินรายการฉากที่เหลือ; เก็บ error และตรวจไฟล์ไม่ว่าง

## สถานะและข้อจำกัด

อ่านขั้นตอนและผลที่ผู้เขียนรายงาน ไม่ได้ฟังเสียง ดูภาพ/คลิป หรือสร้างหนังซ้ำ; ราคา สิทธิ์โมเดล และเงื่อนไขเชิงพาณิชย์ต้องตรวจต้นทางใหม่ก่อนใช้จริง

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

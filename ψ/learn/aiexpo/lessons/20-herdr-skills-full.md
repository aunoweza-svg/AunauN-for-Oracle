# 20. Herdr ทุกสกิล ฉบับเต็ม

ต้นทาง: [herdr ทุกสกิล ฉบับเต็ม](https://aiexpo.buildwithoracle.com/2026-11-08_herdr-skills-full/README.md) · [สำเนาที่อ่าน](../sources/2026-11-08_herdr-skills-full.md)

## แก่นของบท

บทนี้เป็นคลังอ้างอิงของ workflow 52 ตัว พร้อมลิงก์ไฟล์ประกอบ ไม่ใช่คำสั่งให้ติดตั้งและรันทั้งชุด

## สิ่งที่เรียนรู้

- สำรวจหน้าที่และขอบเขตของสกิลครบทั้ง 52 ตัว แล้วแยกชื่อ คำอธิบาย และบรรทัดต้นทางไว้ให้ค้นต่อ
- มีทั้งขั้นตอนอ่านอย่างเดียว ขั้นตอนแก้ Git ขั้นตอนส่งข้อความ และขั้นตอนปิด process จึงต้องเลือกใช้ตามงานจริง
- หลายสกิลเรียก wrapper, token store, fleet, Discord และ repo เฉพาะของผู้เขียน ต้องตรวจ dependency ก่อนนำมาใช้
- ข้อแนะนำบางแห่งต่างจากคู่มือ binary ปัจจุบัน เช่น --current, agent start และรูปแบบ resume จึงใช้ help/skill ของรุ่นที่ติดตั้งเป็นหลัก
- คำสั่ง bypass approvals หรือปิด sandbox ในต้นฉบับเป็นข้อมูลสำหรับศึกษา ไม่ใช่สิทธิ์ให้เปลี่ยนนโยบายเซสชันเรา

## ประยุกต์กับ AunauN

เก็บต้นฉบับเต็มและดัชนี 52 ตัวไว้ใน sources กับ HERDR-SKILLS.md เมื่อจะใช้ตัวใดค่อยอ่าน implementation และทดสอบตัวนั้นกับสภาพแวดล้อมเรา

## สถานะและข้อจำกัด

อ่านเพื่อทำความเข้าใจหน้าที่และ workflow; ยังไม่ได้ตรวจโค้ดทุกบรรทัด audit 106 ไฟล์ หรือดาวน์โหลดไฟล์ประกอบทั้งหมดที่ลิงก์ไว้ และไม่ได้ติดตั้งสกิลเหล่านี้

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

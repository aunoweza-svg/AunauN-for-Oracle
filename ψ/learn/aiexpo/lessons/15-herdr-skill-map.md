# 15. แผนที่ Herdr 52 สกิล

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [แผนที่ skill ของ herdr: 52 ตัว และมันโตมายังไง](https://aiexpo.buildwithoracle.com/2026-11-08_herdr-skill-map/README.md) · [สำเนาที่อ่าน](../sources/2026-11-08_herdr-skill-map.md)

## แก่นของบท

สกิลส่วนเสริมประกอบคำสั่งพื้นฐานเป็น workflow ตามงาน การมีชื่อในแผนที่ไม่ได้แปลว่าเครื่องนี้ติดตั้งแล้ว

## สิ่งที่เรียนรู้

- 7 กลุ่ม: สำรวจ 7, วงจร worktree 14, สื่อสาร 9, ห้องและทีม 6, ย้าย agent 6, หลายเครื่อง 7, พักและเก็บกวาด 3 รวม 52
- เลือก peek เพื่ออ่านสถานะ และ hey เพื่อถาม; เลือก room เพื่อจัด pane เดิม และ team เพื่อเปิดจาก charter
- เริ่มงานที่เหมาะกับ checkout แยกด้วย wt; งานส่งต่อใช้ issue/brief ถาวร และตรวจผลก่อนปิด
- clean-up-sync เป็นชื่อเก่าที่ชี้ไป dissolve จึงต้องแยก alias ออกจากความสามารถใหม่
- ชื่อเครื่อง โครงไฟล์ และคำสั่ง wrapper จำนวนมากเป็นของผู้เขียน อย่าถือเป็นส่วนมาตรฐานของ binary Herdr

## ประยุกต์กับ AunauN

สร้าง HERDR-SKILLS.md เป็นดัชนีครบ 52 ตัวเพื่อเลือกตามโจทย์ โดยตรวจสกิลที่ใช้และ CLI ของเครื่องเราก่อนทุกครั้ง

## สถานะและข้อจำกัด

# 06. Herdr room: รวม pane แล้วส่งกลับ

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [ห้องเดียว หลาย agent: herdr-room in / out](https://aiexpo.buildwithoracle.com/2026-10-31_herdr-room-lesson/README.md) · [สำเนาที่อ่าน](../sources/2026-10-31_herdr-room-lesson.md)

## แก่นของบท

room รวม pane ที่มีอยู่ใน session เดียวกัน จึงเปลี่ยนตำแหน่งการแสดงผลได้โดยไม่ต้องเริ่มบทสนทนาใหม่

## สิ่งที่เรียนรู้

- โครงสร้างคือ session → workspace/space → tab → pane → agent; room เป็นการจัด workspace และ tab ไม่ใช่โมเดล AI ใหม่
- herdr-room มี in/out, layout และ state เก็บสมาชิก; ใช้ dry run ก่อนย้ายแล้วค้น pane id ใหม่จากผลจริง
- ให้ผู้ประสานคนเดียวจัดห้อง ป้องกันการย้ายพร้อมกันจน id และ state เปลี่ยนกลางทาง
- ห้องที่มี pane เกินต้องตรวจสมาชิกจริง ไม่ใช่แก้ state อย่างเดียว; pane ย้ายข้าม session โดยตรงไม่ได้
- เดโม roomlab ใช้ shell ที่รายงานตัวเป็น agent จึงพิสูจน์การจัด pane แต่ไม่ได้เท่ากับทดสอบ AI ทำงานทุกตัวจริง

## ประยุกต์กับ AunauN

เหมาะเมื่อคุณอั๋นต้องการเห็น AunauN, PRISM, Lumina และ AXIOM ในหน้าเดียว ต้องสำรวจพื้นที่และสิทธิ์ก่อน ไม่ย้ายจากคำขอให้อ่านบทเรียน

## สถานะและข้อจำกัด

มีบันทึกก่อนหน้าว่าอ่านและเตรียม Herdr แล้ว รอบนี้ไม่ได้ทดสอบ room in/out หรือรันสคริปต์ใน sources

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

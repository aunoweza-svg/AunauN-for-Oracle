# 21. หนังสือ Herdr สี่สกิล

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [herdr 4 สกิล: เปิดงาน ดึง agent เซ็น PR ปิดงาน](https://aiexpo.buildwithoracle.com/2026-11-08_herdr-four-skills-book/README.md) · [สำเนาที่อ่าน](../sources/2026-11-08_herdr-four-skills-book.md)

## แก่นของบท

หนังสือเชื่อมหลักฐานหลายแบบเพื่ออธิบาย workflow โดยไม่อ้างว่าเดโมรันซ้ำแล้วหากใช้แค่ประวัติเดิม

## สิ่งที่เรียนรู้

- สี่ตัวหลักคือ wt เปิดงาน, bring นำ agent เข้ามา, pr ระบุผู้สร้าง และ dissolve จบพื้นที่ทำงาน
- README ระบุว่า captures สำหรับหนังสือเป็นการตรวจอ่าน ส่วนผลรันจริงอ้าง relic5, GitHub และ tombstone
- เหตุการณ์ rename และ bring ในคืนตัวอย่างไม่ได้อยู่ในงาน issue เดียวทั้งหมด จึงห้ามเล่าเป็นเส้นงานเดียวโดยรวมตามใจ
- herdr-sign ตัด private fields เมื่อ visibility ไม่ชัด; tombstone แยกการเขียนบันทึกออกจากการลบ worktree และใช้ dry run เป็นค่าเริ่มต้น
- ตรวจ ignored data และเก็บบริบทก่อน cleanup ตัวอย่างในบทมีข้อมูลที่ git status ไม่แสดง

## ประยุกต์กับ AunauN

ใช้มาตรฐานการบันทึกเดียวกันกับงานเรา: ระบุว่าอ่านจากแหล่งไหน ทดลองอะไรจริง และส่วนใดยังไม่ได้ยืนยัน

## สถานะและข้อจำกัด

อ่านเนื้อหาหนังสือฉบับ Markdown ที่รวมใน README แล้ว ไม่ได้เปิด PDF 100 หน้า ดูภาพทั้งหมด หรือ audit ภาคผนวก 09-code.md แยกต่างหาก

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

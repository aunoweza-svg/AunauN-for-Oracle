# 09. MCP ส่ง skill และ media

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [MCP ตัวเดียว ส่งได้ทั้ง skill เสียง และวิดีโอ](https://aiexpo.buildwithoracle.com/2026-11-04_skills-media-mcp-lesson/README.md) · [สำเนาที่อ่าน](../sources/2026-11-04_skills-media-mcp-lesson.md)

## แก่นของบท

MCP สามารถแจกเอกสารขั้นตอนและ transcript ที่มีเวลาได้ นอกเหนือจากการค้นบทเรียน แต่ข้อมูลที่ได้ไม่ใช่สิทธิ์ให้รันทุกขั้นตอน

## สิ่งที่เรียนรู้

- list_skills/get_skill ส่ง skill ฉบับเต็มเป็น Markdown/resource; list_media/get_media ส่งรายการและคำพูดพร้อมเวลา
- วงจร awaken → งาน → rrr → forward บนเว็บต้องส่งไฟล์ออกมาเพื่อให้แชทถัดไปมีบริบท
- คำสั่ง recap ที่พึ่งไฟล์ในเครื่องต่างจาก where-we-are ที่สรุปจากบทสนทนาปัจจุบันได้
- การเพิ่ม tools อาจต้อง reconnect หรือ refresh ฝั่ง client; รายการที่เห็นเก่าอาจทำให้ AI สรุปผิดว่าไม่มีสื่อ
- transcript อัตโนมัติอาจคลาดจากเสียง ต้องตรวจจุดสำคัญก่อนอ้างคำพูด

## ประยุกต์กับ AunauN

ใช้ไฟล์ความจำใน repo เป็นหลักเมื่อทำงานที่นี่ และเก็บลิงก์พร้อมเวลาเมื่อต้องอ้างสื่อ workshop

## สถานะและข้อจำกัด

ไม่ได้ติดตั้ง skill ที่ดาวน์โหลด ไม่ได้เรียกวงจร rrr หรือ forward ในรอบนี้ และไม่ได้ดูคลิปทั้งหมด

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

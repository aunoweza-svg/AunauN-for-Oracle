# 13. ติดตั้ง relic5 และนำเข้าประวัติ

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [ติดตั้ง relic5: ประวัติทุก session ของทุกเครื่อง ในฮับเดียว](https://aiexpo.buildwithoracle.com/2026-11-04_relic5-install/README.md) · [สำเนาที่อ่าน](../sources/2026-11-04_relic5-install.md)

## แก่นของบท

การตั้ง CLI กับการนำประวัติส่วนตัวขึ้นฮับเป็นคนละการกระทำ ต้องเห็นปลายทางและขอบเขตข้อมูลก่อน import

## สิ่งที่เรียนรู้

- สายงานในบทคือ scan → extract → push → index → embed → sync และให้ตรวจ mismatch กับ pending หลังส่ง
- ชื่อเครื่องเป็นส่วนของตำแหน่งข้อมูล จึงต้องตั้งให้ถูกก่อนนำเข้าครั้งแรก
- บทใช้ Python core กับ Rust CLI และมีส่วน extract ที่ต้นฉบับระบุว่ายังเป็น private; ไม่ใช่ทุกขั้น clone public repo แล้วจบ
- ตัวอย่าง import เป็น manual ตามข้อตกลงของเจ้าของระบบ ไม่ควรตีความว่าเปิด sync อัตโนมัติได้
- ขอบเขตการเข้าถึงใน tailnet และ token เป็นของ deployment ตัวอย่าง ต้องออกแบบใหม่สำหรับข้อมูลของเรา

## ประยุกต์กับ AunauN

ถ้าต้องการฮับทีม AunauN ให้เริ่มจากการกำหนดข้อมูลที่ส่งได้ เครื่องที่เก็บ และการกู้คืน ก่อนเลือกระบบและ import

## สถานะและข้อจำกัด

ยังไม่ได้ติดตั้ง relic5, ส่ง transcript, สร้าง token, เชื่อมบัญชี หรือทดสอบ restore

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

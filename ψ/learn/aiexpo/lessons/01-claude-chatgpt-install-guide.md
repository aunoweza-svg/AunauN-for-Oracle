# 01. เตรียมเครื่องและสกิล Oracle

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [ติดตั้ง Claude และ ChatGPT ให้พร้อมเข้า workshop](https://aiexpo.buildwithoracle.com/2026-10-30_claude-chatgpt-install-guide/README.md) · [สำเนาที่อ่าน](../sources/2026-10-30_claude-chatgpt-install-guide.md)

## แก่นของบท

แยกตัวแอปแชท ตัว coding agent และสกิลออกจากกัน ความจำข้ามรอบต้องอาศัยไฟล์หรือระบบเก็บข้อมูลที่เปิดกลับมาได้

## สิ่งที่เรียนรู้

- เส้นทางในบทมี Claude Code, Codex CLI และ claude.ai โดยความสามารถเข้าถึงไฟล์และเก็บความจำต่างกัน
- การติดตั้งไม่จบที่มีโฟลเดอร์ SKILL.md ต้องเปิดเซสชันแล้วพิสูจน์ว่า agent มองเห็นสกิลจริง
- วงจรที่ควรเข้าใจคือ awaken สร้างตัวตน → ทำงาน → rrr เก็บบทเรียน → forward ส่งต่อ → กลับมาอ่านความจำ
- บทพูดถึงการติดตั้งแบบ plugin, installer และ ZIP บนเว็บ ซึ่งเป็นวิธีของแพลตฟอร์มและวันที่ในบท ไม่ใช่ข้อยืนยันว่าใช้ได้กับบัญชีเราทุกรูปแบบ

## ประยุกต์กับ AunauN

โครงการเรามี CLAUDE.md และ ψ อยู่แล้ว ให้ตรวจสกิลที่เซสชันเปิดให้ใช้จริง แทนการปลุกตัวตนใหม่หรือติดตั้งซ้ำ

## สถานะและข้อจำกัด

ยังไม่ได้ทดสอบ installer, แผนบัญชี, UI เว็บ หรือการโหลดสกิลครบชุดในรอบนี้ ข้ออ้างเกี่ยวกับ OpenAI ต้องตรวจเอกสารทางการและ CLI ปัจจุบันก่อนใช้เป็นคำแนะนำติดตั้ง

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

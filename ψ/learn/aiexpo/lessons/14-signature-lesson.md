# 14. ลายเซ็นดิจิทัลของบทเรียน

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [ลายเซ็นดิจิทัลของบทเรียน: สร้างยังไง ทำงานยังไง](https://aiexpo.buildwithoracle.com/2026-11-04_signature-lesson/README.md) · [สำเนาที่อ่าน](../sources/2026-11-04_signature-lesson.md)

## แก่นของบท

แฮชตรวจว่าไบต์เปลี่ยนหรือไม่ ลายเซ็นตรวจว่ากุญแจใดรับรองข้อความนั้น ทั้งสองอย่างไม่พิสูจน์ว่าข้อความจริงหรือปลอดภัย

## สิ่งที่เรียนรู้

- ต้นฉบับรวม hash ของ README ไทย อังกฤษ และ Base64 ไว้ใน manifest แล้วเซ็นข้อความด้วย EIP-191
- การตรวจประกอบด้วยคำนวณ hash ใหม่ ตรวจ Base64 ตรงกับไทย และ recover address เพื่อเทียบกับตัวตนที่คาดไว้
- ต้องรู้ว่าที่อยู่ที่เชื่อถือคืออะไร การเทียบกับ claimed address ที่ผู้โจมตีเปลี่ยนได้อย่างเดียวไม่พอ
- การแก้เนื้อหาต้องเซ็นใหม่; ตัวอย่างทดลองใช้กุญแจชั่วคราวแยกจากกุญแจจริง
- คำว่า Built by บน PR ในบท Herdr เป็นข้อมูลที่มา ต่างจากการเซ็นแบบ cryptographic ในบทนี้

## ประยุกต์กับ AunauN

รอบนี้เก็บ SHA-256 ของสำเนาที่ดาวน์โหลดเพื่อจับการเปลี่ยนภายหลัง แต่ยังไม่ได้ยืนยัน Ethereum signature ของต้นทาง

## สถานะและข้อจำกัด

ไม่ได้ดาวน์โหลดชุด manifest/สามภาษาและรัน verifier จึงห้ามเรียกชุดสำเนานี้ว่า verified signature

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

# 03. เชื่อม MCP ของบทเรียน

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [ต่อ claude.ai และ ChatGPT เข้ากับ MCP ของบทเรียน](https://aiexpo.buildwithoracle.com/2026-10-30_mcp-connect-guide/README.md) · [สำเนาที่อ่าน](../sources/2026-10-30_mcp-connect-guide.md)

## แก่นของบท

MCP ทำให้ AI ค้น อ่าน และรับภาพจากแหล่งข้อมูลผ่าน schema ที่ client รู้จัก การมี config ยังไม่พิสูจน์ว่าเซสชันเรียกเครื่องมือได้

## สิ่งที่เรียนรู้

- บทอธิบาย endpoint แบบ Streamable HTTP และวิธีต่อผ่าน Claude Code, Codex, claude.ai และ ChatGPT
- รายชื่อเครื่องมืออาจถูก client cache ไว้ ต้องตรวจ tools/list และความสามารถที่เซสชันเห็นจริง
- แยกโมเดลได้รับ image content ออกจากหน้าแชทแสดงภาพได้หรือไม่
- เอกสารส่วนต้นและ captures บางช่วงพูดถึงจำนวนเครื่องมือต่างกัน เพราะเพิ่มจากชุดบทเรียนไปสู่ skill และ media ภายหลัง

## ประยุกต์กับ AunauN

รอบนี้ไม่มี AIExpo MCP ในรายการเครื่องมือที่เปิดให้เซสชัน จึงอ่านผ่าน HTTPS GET และเก็บต้นฉบับ ไม่อ้างว่ามี MCP พร้อมใช้เพราะบันทึกเก่าระบุว่าเคยตั้งค่า

## สถานะและข้อจำกัด

ไม่ได้เปลี่ยน MCP config หรือทดสอบ connector UI; ก่อนเชื่อมจริงต้องอ่าน schema และขั้นตอนปัจจุบันของ client

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

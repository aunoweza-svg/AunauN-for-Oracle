# 19. Herdr หลายเครื่อง

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [herdr หลายเครื่อง: เพิ่มเครื่อง ย้ายทีมไป white คุยข้ามเครื่อง](https://aiexpo.buildwithoracle.com/2026-11-08_herdr-machines/README.md) · [สำเนาที่อ่าน](../sources/2026-11-08_herdr-machines.md)

## แก่นของบท

saved machine เป็นเส้นทางไปยัง remote session ที่ระบุไว้ การสั่งข้ามเครื่องต้องใช้ selector เดียวกันตั้งแต่ค้นจนตรวจผล

## สิ่งที่เรียนรู้

- บทใช้ SSH/Tailscale ใต้การเชื่อม Herdr และแสดงการส่งไฟล์กับข้อความไปกลับ
- ต้องตรวจสิทธิ์ขากลับแยกจากขาไป การส่งออกได้ไม่ได้ยืนยันว่าปลายทางตอบกลับได้
- การย้ายทีมรวม config, transcript, launch environment และ bot state ไม่ใช่แค่ copy repo
- labels, fold และ disable มีผลต่างกัน และรายการ machine อาจใช้ร่วมหลายหน้าต่าง ต้องตรวจขอบเขตก่อนเปลี่ยน
- เดโมมีสคริปต์ --merge อัตโนมัติ แต่กฎของ repo เราห้าม merge PR โดยไม่มีอำนาจจากมนุษย์

## ประยุกต์กับ AunauN

หากทีม AunauN ขยายหลายเครื่องให้ทดลองไปกลับกับเป้าหมายที่ระบุแน่ชัดก่อน และเก็บหลักฐาน identity, delivery, reply และ continuity

## สถานะและข้อจำกัด

ไม่ได้เพิ่ม machine, ตั้ง SSH/Tailscale, ส่งไฟล์ข้ามเครื่อง หรือย้ายทีมในรอบนี้

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

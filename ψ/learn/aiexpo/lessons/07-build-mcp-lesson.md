# 07. สร้าง MCP จากเล็กไปใหญ่

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [สร้าง MCP ของตัวเอง: จากบทเรียนเป็นเครื่องมือให้ AI](https://aiexpo.buildwithoracle.com/2026-11-02_build-mcp-lesson/README.md) · [สำเนาที่อ่าน](../sources/2026-11-02_build-mcp-lesson.md)

## แก่นของบท

เริ่มจาก JSON-RPC ที่ตอบ initialize, tools/list และ tools/call แล้วแยกการเตรียมข้อมูลออกจากการค้นและเสิร์ฟผล

## สิ่งที่เรียนรู้

- ตัวอย่างเริ่มจาก stdio server ขนาดเล็ก แล้วขยายเป็น Cloudflare Worker และ stdio จาก GitHub
- notification ไม่มี id ไม่ควรตอบแบบ request; error ควรมีโครงสร้างที่ client แยกสาเหตุได้
- ตัด Markdown เป็น section โดยเคารพ code fence เก็บ id กับ URL ให้คงที่ และเตรียมภาพล่วงหน้า
- การค้นในตัวอย่างผสมเวกเตอร์หลายภาษากับคำค้น และลดระดับเป็น keyword เมื่อ embedding ใช้ไม่ได้
- ทดสอบด้วย request เดียวกันทั้งสอง transport และ client จริง ตรวจว่า Worker ได้รับเส้นทางก่อน static assets

## ประยุกต์กับ AunauN

ใช้เป็นแนวทางทำคลังเอกสารท่องเที่ยว: ค้น → อ่านชิ้นต้นทาง → ดูภาพ → อ้างที่มา โดยเริ่มเครื่องมืออ่านอย่างเดียวและมีผลทดสอบที่เทียบกันได้

## สถานะและข้อจำกัด

ไม่ได้ deploy Worker รัน mini server หรือทดสอบ MCP protocol ในรอบนี้ โค้ดตัวอย่างต้องตรวจความครบและสเปกปัจจุบันก่อนใช้งานจริง

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

# 08. Antigravity CLI กับ MCP

วันที่ศึกษา: 2026-11-11 (Asia/Bangkok) · ผู้สรุป: AunauN Oracle (AI)

ต้นทาง: [ใช้ Antigravity CLI (agy) กับ MCP ของบทเรียน](https://aiexpo.buildwithoracle.com/2026-11-02_agy-mcp-lesson/README.md) · [สำเนาที่อ่าน](../sources/2026-11-02_agy-mcp-lesson.md)

## แก่นของบท

แอป desktop กับ CLI อาจติดตั้งแยก และความพร้อมต้องยืนยันตั้งแต่ login จนถึงการเรียก MCP จริง

## สิ่งที่เรียนรู้

- บทติดตั้ง agy แล้วเชื่อม HTTP และ stdio MCP สองเส้นทาง
- OAuth URL ที่ถูกตัดระหว่าง copy ทำให้ดูเหมือน scope ผิด ต้องตรวจ URL ครบก่อนวินิจฉัยสิทธิ์
- อ่านตัวเลือกแชร์ข้อมูลที่ติ๊กมาให้ก่อนยืนยัน; ขั้นตอน login เป็นส่วนที่มนุษย์ทำ
- ลำดับ flag ในคำสั่งของเวอร์ชันตัวอย่างสำคัญ และ server enabled ไม่เท่ากับ agent ใช้ tool แล้ว ต้องเห็นผล tools/call

## ประยุกต์กับ AunauN

หากเพิ่ม Google agent ให้ทีม ควรทดสอบตั้งแต่ CLI ถึงคำตอบจากแหล่งจริงก่อนจัดเป็นตัวที่พร้อมรับงาน

## สถานะและข้อจำกัด

ไม่ได้ติดตั้ง agy ล็อกอิน หรือใช้โควตาบัญชี; ข้อมูลรุ่นและโมเดลเป็นบันทึกของต้นฉบับ ไม่ได้ยืนยันปัจจุบัน

ข้อเท็จจริงเกี่ยวกับระบบของผู้เขียนเป็นข้อมูลตามวันที่ในต้นฉบับ การประยุกต์ข้างต้นเป็นข้อเสนอของผู้สรุป ไม่ใช่ผลทดสอบใหม่

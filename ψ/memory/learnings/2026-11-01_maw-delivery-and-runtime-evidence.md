# Live agent handoffs need end-to-end evidence

A running agent pane is not a shared conversation or proof of a registered fleet. Resolve the target and working directory, send a complete message, confirm that it was submitted rather than left in the input, and read an attributed response. In this session a long maw message needed an additional Enter before PRISM began work.

When reporting implementation readiness, name the tested layer. PRISM's Node harness exposed a journal failure and HTTP checks retrieved Binance data, but neither establishes browser rendering, browser storage or CORS behavior. Treat those as separate acceptance checks.

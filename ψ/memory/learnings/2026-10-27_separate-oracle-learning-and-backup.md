# เรียนรู้และสำรอง Oracle ที่มี repo แยก

เมื่อศึกษา repository ภายนอก บันทึก commit, แหล่งที่มา และข้อจำกัด โดยแยกว่าทำเพียงอ่านซอร์ส ติดตั้งเครื่องมือ หรือทดสอบ runtime แล้วจริง เพราะแต่ละขั้นให้หลักฐานต่างกัน

Git repository ที่ซ้อนใน workspace ไม่ได้สำรองประวัติไปกับ repo แม่โดยอัตโนมัติ หากยังไม่มี remote ที่ได้รับอนุญาต อาจเก็บ snapshot ไฟล์งานเป็นเอกสารธรรมดาใน repo ที่มีปลายทางชัดเจน โดยไม่รวม `.git`, source clone หรือ secrets พร้อมบอกวิธีคืนค่าและข้อจำกัดว่า snapshot ไม่ใช่ประวัติ Git

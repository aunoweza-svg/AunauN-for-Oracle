# เลือกและตรวจสกิลก่อนใช้งาน

เริ่มจากศึกษาบทบาทและข้อจำกัด เลือกสกิลที่ตอบโจทย์แทนติดตั้งทั้งชุด จากนั้นตรึง commit ต้นทางและตรวจ hash ทุกไฟล์รวม references พร้อมเก็บ license เมื่อสำรอง การมีไฟล์ตรงต้นทางไม่ได้พิสูจน์ว่า host โหลดสกิลหรือ workflow ทำงานสำเร็จ

ตรวจ dependencies และผลข้างเคียงของ workflow เช่น spec, issue tracker, subagents และสกิลอื่นตามเงื่อนไข ก่อนใช้งานจริงให้ปฏิบัติตามคำสั่งผู้ใช้และข้อกำหนดของ host ที่มีผล

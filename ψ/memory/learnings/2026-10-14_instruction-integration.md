# ผสานแม่แบบคำแนะนำโดยรักษาบริบทเดิม

ก่อนใช้แม่แบบภายนอก ให้อ่านคำแนะนำปัจจุบันและเทียบตัวตน เป้าหมาย ขั้นตอนทำงาน เกณฑ์ตรวจผล และการส่งต่องาน เพิ่มเฉพาะส่วนที่ขาดและตรงกับงานจริง เก็บบันทึกเดิมเป็นประวัติเมื่อปรับรายการความสามารถ

แยกข้อมูลสามชั้น: หลักการของโปรเจกต์ วิธีทำงานของสกิล และสิทธิ์หรือข้อจำกัดของโฮสต์ที่กำลังใช้ พาธ เครื่องมือ และข้อจำกัดการสร้างเอเจนต์อาจเปลี่ยนเมื่อย้ายเครื่อง จึงควรตรวจขณะใช้งานแทนการฝังเป็นกฎถาวรโดยไม่จำเป็น

ไฟล์สกิลที่อ่านได้ ซอร์ส CLI และคำสั่งใน PATH ไม่ใช่สิ่งเดียวกัน การไม่พบคำสั่งยืนยันได้เพียงว่าเรียกผ่าน PATH ไม่ได้ในสภาพแวดล้อมที่ตรวจ ไม่ยืนยันว่าโปรแกรมไม่มีอยู่ทั้งเครื่อง การเพิ่มประสิทธิภาพควรวัดจากผลลัพธ์ของงานและขั้นตอนที่ลดลง ไม่ใช่จำนวนสกิล

เมื่อบันทึกย้อนหลัง ให้ใช้เวลาที่มีหลักฐานและระบุช่องว่างตรงไปตรงมา ความจำส่วนกลางกับการเข้าถึงเอเจนต์จากอีกอุปกรณ์เป็นคนละความสามารถ ต้องตรวจการตั้งค่าแต่ละส่วนแยกกัน

# ตรวจค่าครบอย่างเดียวไม่พอ ต้องตรวจว่าอยู่ถูกช่อง

ข้อความที่สกัดจาก PDF อาจมีตัวเลขครบแต่สลับหน่วย ภูมิภาค หรือช่วงเวลา การแก้เอกสารควรแยกสามกรณี: ค่าที่ผิดจริง การจับคู่ค่ากับหัวข้อผิด และความกำกวมที่มีในต้นฉบับเอง

## วิธีที่นำไปใช้ซ้ำได้

1. เก็บสำเนาก่อนแก้และตรวจ hash เมื่อคัดลอก เพื่อย้อนสอบได้; ระวัง Copy-Item รักษา LastWriteTime ของต้นทางไว้ จึงไม่ใช่เวลาสร้างสำเนา
2. แยกปีสำรวจ ปีอ้างอิงอายุ และปีแผนงาน ห้ามเลื่อนข้อมูลเก่าเป็นข้อมูลปีใหม่ ช่วงอายุอาจคำนวณใหม่ได้เมื่อระบุฐานปีและปีเกิดชัดเจน
3. เรนเดอร์หน้าที่เกี่ยวข้องเพื่อเห็นหัวข้อและตำแหน่งจริง ถอดข้อความแบบ layout เพื่ออ่านค่า และผูกค่าแต่ละชุดกับหน้า PDF
4. ตรวจค่ารายหน้าและจำนวนครั้งที่ปรากฏเพื่อหาค่าหาย/เพิ่ม แล้วตรวจแยกคอลัมน์หรือเซลล์อิสระเพื่อจับการสลับช่อง การผ่าน multiset อย่างเดียวไม่ยืนยันว่าความหมายถูก
5. ตรวจผลรวมเฉพาะกลุ่มที่ยืนยันว่าเป็นส่วนเติมเต็ม เช่น เมืองหลัก/เมืองน่าเที่ยว หรือแชร์/ไม่แชร์ ไม่บังคับกิจกรรมและช่องทางที่อาจตอบได้หลายข้อให้รวม 100%
6. เมื่อภาพอ่านไม่ชัด ให้ซูมก่อนรายงานว่าต้นฉบับผิด หากต้นฉบับเองกำกวมให้คงค่าและป้ายเดิมพร้อมหมายเหตุ แทนการเดาว่าควรแก้เป็นอะไร
7. ตรวจไฟล์ที่บันทึกจริง รวมจำนวนหัวข้อ การเว้นบรรทัด ตาราง ลิงก์อ้างอิง และความตรงกับข้อมูลที่ตรวจแล้ว การตรงกับข้อความที่สร้างขึ้นไม่ใช่การตรวจรูปแบบอิสระ

## ข้อสังเกตด้านเครื่องมือ

- คำสั่งชื่อเดียวกันอาจมาจากคนละชุดเครื่องมือ; Xpdf pdftotext และ Poppler pdftotext รองรับ option ต่างกัน ตรวจ help/version ก่อนใช้
- บน Windows อาจพบ Xpdf ในโฟลเดอร์ Git แม้ไม่อยู่ใน PATH และอาจใช้ Windows.Data.Pdf เรนเดอร์ได้ ตรวจความพร้อมขณะทำงาน ไม่ถือว่าตำแหน่งเหล่านี้จะเหมือนกันทุกเครื่อง
- การไม่พบเครื่องมือใน PATH ไม่พิสูจน์ว่าไม่มีอยู่ทั้งเครื่อง และตัวเรียก Microsoft Store ไม่ได้ยืนยันว่ามี interpreter ที่พร้อมใช้

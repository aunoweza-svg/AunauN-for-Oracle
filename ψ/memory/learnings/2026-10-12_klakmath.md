# Learned KlakMath

KlakMath is a small Unity package (`jp.keijiro.klak.math`) that extends Unity Mathematics with exponential and critically damped tweening, deterministic XXHash-based values and geometric samples, one-dimensional gradient/fractal noise, random sampling extensions, and a vector-to-vector rotation helper.

Its design is deliberately direct: most features are static functions over Unity Mathematics value types. `XXHash` is a readonly seeded value type, and `Noise` layers gradient generation and fractal octaves on top of it. The repository doubles as a Unity demo project, while the distributable runtime lives under `Packages/jp.keijiro.klak.math`.

# Learned REA

Source reviewed at commit `569ef4159db73931717825302b323fae7aa91bbf`; no installation or runtime verification.

- REA is a CLI/MCP analysis tool, with shared workflows and provider-specific capabilities. Static JavaScript/Electron analysis does not require a native decompiler.
- `src/domain/evidence.ts` distinguishes observed/derived/inferred evidence and records limitations and locations. `src/application/WorkflowEvidence.ts` carries upstream limitations into composed findings.
- Windows Ghidra support is experimental and read-only; its host, filesystem, Ghidra/JDK and target restrictions must be checked for the selected release.

Potential fit for AunauN: understand app/site behavior and learn implementation patterns with evidence. This fit is an inference, not a tested result or a replacement for tourism/market data.

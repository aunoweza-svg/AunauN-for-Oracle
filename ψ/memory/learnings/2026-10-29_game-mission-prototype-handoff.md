# ต้นแบบภารกิจและการส่งมอบ

การเพิ่ม checklist ไม่ได้ทำให้ประสบการณ์ดูเป็นเกมโดยอัตโนมัติ ต้องออกแบบภาพ ลำดับภารกิจ feedback และแผนที่ร่วมกัน แล้วตรวจหน้าจอจริงกับผู้ใช้ก่อนอ้างว่าตรงเป้าหมาย สำหรับกิจกรรมที่ใช้แสตมป์กระดาษ ให้แยกเครื่องหมายช่วยจำออกจากการรับรองสิทธิ์จริงอย่างชัดเจน

Local preview ต้องมีเซิร์ฟเวอร์ทำงานอยู่เมื่อผู้ใช้เปิดลิงก์ และต้องสื่อสาร lifecycle ให้ชัด `localhost` กับ `127.0.0.1` เป็นคนละ origin จึงไม่แชร์ localStorage รวมถึงคีย์แผนที่และความคืบหน้า ควรให้ผู้ใช้กรอกคีย์เอง ไม่เก็บคีย์ลง source หรือ memory

การปรับกรอบแผนที่และหน้ารายการไม่เท่ากับเปลี่ยนสไตล์พื้นแผนที่ของ Google และ HTTP 200 หรือ unit test ไม่ใช่หลักฐานการแสดงผลจริงบนเบราว์เซอร์หรือมือถือ หาก browser host ไม่พร้อม ให้ระบุข้อจำกัดและทดสอบกับผู้ใช้ภายหลัง

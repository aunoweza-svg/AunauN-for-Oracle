# File handoff is not a live connection

A local Oracle repository and inbox identify a place to leave a message; they do not establish that an agent is running, has received a notification, or has replied. Verify the destination and available transport, record the sender and request, and label the message as pending. If presenting an introduction based on identity files, say it is a portrayal based on those files, not a response from another session. Keep machine-specific contact paths and independent nested repositories in mind when preparing a portable backup.

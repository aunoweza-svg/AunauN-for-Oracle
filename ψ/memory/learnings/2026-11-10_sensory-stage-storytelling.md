# เล่าให้รู้สึก แล้วให้ผู้ฟังเลือกเดินทางได้

บทพูดท่องเที่ยวต้องมีทั้งอารมณ์และสิ่งที่ผู้ฟังนำไปใช้ได้ แบ่งคำถามให้ทำหน้าที่ต่างกัน: ข้อแรกบอกความหมายและความรู้สึก ข้อถัดไปพาเดินทางตามตัวอย่างที่เป็นไปได้ และข้อปิดเปิดภาพพื้นที่ให้กว้างขึ้นด้วยสถานที่และประสบการณ์ที่ต่างจากเส้นทางเดิม

ระบุสิ่งที่มองเห็น ได้ยิน ชิม หรือเรียนรู้โดยมีแหล่งข้อมูลรองรับ ไม่รับรองหมอก ดาว สิทธิประโยชน์ หรือบริการที่ยังไม่ยืนยัน ตรวจแหล่งข้อมูลและเงื่อนไขใกล้วันจริง ซ้อมจับเวลาแทนการอนุมานจากความยาวข้อความ

เมื่อปรึกษา Oracle ผ่าน maw ให้ตรวจ repository และการส่งจริง อ่านคำตอบที่ระบุผู้ตอบได้ และแยกความสำเร็จในการส่งจากการเปิดหน้าต่างให้ผู้ใช้เห็น

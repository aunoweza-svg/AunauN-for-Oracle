## What Went Well

- User confirmed Google Maps appeared after the key guidance.
- Existing `test.cjs` passed 62-place counts, filters, search and corrected location; new CSS and illustration returned HTTP 200.

## What Could Improve

- Agree on and inspect a recognizably game-like visual direction before treating the first checklist as a meaningful design outcome.
- Keep local preview accessible at handoff and explain browser origin and server lifetime.
- Test the final page and interactions in a real browser and mobile viewport before claiming visual quality.

## Blockers & Resolutions

- Preview failed because the server had been stopped; restarted and observed HTTP 200. Long-term availability still depends on a running process or the launcher.
- Map showed missing API key; explained origin-specific storage and retrieval; user reported the map appeared. No credential was recorded.
- Browser access host unavailable during the earlier QA attempt; source checks and HTTP tests passed but real visual and mobile verification remain open.
- Google basemap remains standard; custom basemap styling or an illustrated map layer remains future design work.

## Lessons Learned

- **Pattern**: ทดสอบภาพ ลำดับ และ feedback ของประสบการณ์เกมร่วมกัน ไม่สรุปจาก checklist เพียงอย่างเดียว
- **Mistake**: อย่าปิด local server ก่อนส่งลิงก์ให้ผู้ใช้ และอย่าถือ HTTP 200 ว่าเป็น visual QA
- **Discovery**: localStorage แยกตาม origin จึงต้องระวังทั้งคีย์แผนที่และ progress เมื่อสลับ hostname

## Recurring Pattern

ใน metrics เจ็ดแถวล่าสุดพบข้อจำกัดเครื่องมือหรือ host readiness อย่างน้อยสามครั้ง จึงควรตรวจ browser/runtime และขอบเขตหลักฐานตั้งแต่ต้น

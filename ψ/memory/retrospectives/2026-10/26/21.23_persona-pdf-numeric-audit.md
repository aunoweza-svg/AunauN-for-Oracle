## Blockers & Resolutions

- **Markdown หลายคอลัมน์ปะปน**: แรกเริ่มตรวจได้เฉพาะหน่วยและค่าที่จับคู่ชัด ผู้ใช้เพิ่ม PDF แล้วจึงเรนเดอร์และเทียบตำแหน่งครบ ส่วนตัวเลขเสร็จ; เหลือสามข้อกำกวมในต้นฉบับซึ่งบันทึกไว้
- **เครื่องมือ PDF/สคริปต์**: ไม่พบ Poppler ใน PATH; พบ Xpdf ใน Git ตัวเลือก bbox ใช้ไม่ได้จึงใช้ layout และ margin แยกคอลัมน์แทน; สคริปต์ .ps1 เรียกตรงติด execution policy จึงรันเนื้อหาโค้ดที่สร้างเองในโปรเซสปัจจุบัน โดยไม่ได้เปลี่ยนนโยบายระบบ
- **session clock ไฟล์กำลังถูกใช้งาน**: OpenText แบบเดิมเปิดไม่ได้ เปลี่ยนเป็นอ่านด้วย FileShare.ReadWrite และยืนยัน session ID/cwd ก่อนสแกนเฉพาะ timestamp สำเร็จ ไม่ทำ full session mining

3. ด้านการสื่อสาร ผมประกาศข้อสงสัยเรื่องคู่ร้อยละเหมือนเป็นข้อผิดพลาดของต้นฉบับเร็วเกินไป แล้วจึงต้องแก้คำอธิบายเมื่อซูมภาพ นอกจากนี้คำว่าแก้เสร็จแล้วต้องครอบคลุมทั้งไฟล์ที่บันทึกจริงและข้อจำกัดที่ยังอยู่ ผู้ใช้ถามยืนยันว่า MD ถูกแก้แล้วหรือยัง ผมจึงควรส่งมอบให้ชัดในครั้งเดียวว่าไฟล์ใดเปลี่ยน ตรวจอะไรผ่าน และส่วนใดเป็นความกำกวมจากผู้จัดทำต้นฉบับ

## Lessons Learned

- **Pattern**: ตรวจตาราง PDF สองชั้น คือค่าครบและอยู่ถูกช่อง; multiset ของตัวเลขอย่างเดียวไม่จับการสลับคอลัมน์
- **Mistake**: อย่าประกาศว่าต้นฉบับผิดจากภาพที่ยังอ่านไม่ชัด หรือถือว่าผลตรวจค่าผ่านเท่ากับโครงสร้างเอกสารผ่าน
- **Discovery**: Xpdf ที่อยู่ใน Git และ Windows.Data.Pdf ใช้ทำงานถอดข้อความ/เรนเดอร์บน Windows ได้ เมื่อเครื่องมือที่คุ้นเคยไม่พร้อมผ่าน PATH
- บันทึกหลักปฏิบัติถาวรใน lesson แยกไว้แล้ว ไม่เขียนเพิ่มใน CLAUDE.md หรือ AGENTS.md

## Blockers & Resolutions

- **Git metadata อ่านอย่างเดียวใน sandbox**: fetch เขียน FETCH_HEAD ไม่ได้และการ stage ต้องเขียน index จึงขอ escalation ตามข้อจำกัดระบบ แล้วดำเนินการได้ ไม่ใช้ force หรือ reset
- **เครือข่ายผ่าน proxy ใน sandbox**: git ls-remote ครั้งแรกเชื่อมต่อไม่ได้ เรียกใหม่ด้วย escalation แล้วตรวจ remote SHA สำเร็จ
- **working tree มีงานอื่นและไฟล์ metrics ร่วมกัน**: ใช้รายการไฟล์เฉพาะและ index patch; ตรวจ cached diff ก่อน commit จึงไม่พาอีกงานขึ้น remote
- **อ่านแผนครั้งแรก output ถูกตัด**: อ่านซ้ำแบ่งช่วง 1–60, 61–116 และ 117–167 จนครบ และตรวจผลรวมด้วยการคำนวณ
- ไม่มี blocker ค้างในงาน push และงานอ่านที่ผู้ใช้มอบหมาย; ข้อสงสัยในเนื้อหาแผนถูกบันทึกไว้ ไม่เดาคำตอบแทนผู้จัดทำ

## Lessons Learned

- **Pattern**: ก่อน push ให้ตรวจขอบเขตจาก index และหลัง push ให้ยืนยัน remote; working tree ที่มีหลายงานไม่ควรเผยแพร่ทั้งหมดเพียงเพราะอยู่ repository เดียวกัน
- **Mistake**: จำนวนบรรทัดน้อยไม่ได้แปลว่าตาราง Markdown สั้น การอ่านก้อนใหญ่ยังทำให้ผลถูกตัดได้
- **Discovery**: partial index patch ใช้เก็บเฉพาะแถวของงานหนึ่งในไฟล์ log ร่วมกัน โดยคงอีกแถวไว้ใน working tree

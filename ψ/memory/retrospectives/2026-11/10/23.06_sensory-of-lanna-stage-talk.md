## What Went Well

- คุณอั๋นยืนยันว่าชอบอารมณ์ข้อ 1 และตอบรับข้อ 2; เส้นทางมีคืนพักชัดเจน
- maw แสดง delivered และ Lumina อ่านร่างจริง พร้อมตอบใน pane ของ repository Lumina
- ค้นข้อมูลท่องเที่ยวจาก ททท. และหน่วยงานจังหวัด โดยไม่รับรองสภาพอากาศหรือโปรโมชั่น

## What Could Improve

- ทดสอบการจับเวลาจริง ไม่ประมาณว่าอ่านครบ 12 นาที
- ให้คำตอบแต่ละข้อมีหน้าที่ต่างกันและเพิ่มสถานที่จริงก่อนพึ่งสโลแกน
- ส่งร่างฉบับเต็มให้ผู้ร่วมร่างตั้งแต่แรก และตรวจช่องทางให้ผู้ใช้เห็น pane ได้จริง

## Blockers & Resolutions

- maw ไม่พบ pane เริ่มต้น จึงเปิดเซสชัน WSL ใน repo Lumina และยืนยันการรับข้อความ; การเปิด Windows Terminal ให้ผู้ใช้เห็นยังไม่ยืนยันสำเร็จ
- สิทธิประโยชน์งานยังไม่มีข้อมูลยืนยัน จึงเว้นพื้นที่ให้ผู้จัดส่งรายละเอียด; ยังไม่ควรอ้างข้อเสนอหรือบูธที่ไม่ยืนยัน
- main ในเครื่องตามหลัง remote 9 commits และมีงานอื่นค้าง ต้องจัด commit จาก remote โดยไม่เปลี่ยนงานค้างในเครื่อง

## 💭 Honest Feedback

1. การกำหนดเวลาไม่ชัดในช่วงแรกทำให้บทฉบับแรกสั้นเกินไปสำหรับผู้พูดคนเดียว ผมควรตรวจความหมายของกรอบเวลาและนำผลไปจัดสัดส่วนการเล่าเรื่องตั้งแต่ต้น แทนการนำสมมติฐานเรื่องผู้ร่วมเวทีไปใช้โดยไม่ระบุข้อจำกัด
2. maw และหน้าต่างที่ผู้ใช้มองเห็นเป็นคนละชั้นของหลักฐาน การตรวจ pane แสดงว่า Lumina ตอบได้ แต่การเรียกเปิด Windows Terminal ไม่พิสูจน์ว่าผู้ใช้เห็นหน้าต่าง ผมต้องรายงานตามที่ตรวจได้และไม่เรียกการส่งโจทย์ว่าเป็นการเปิดหน้าจอ
3. บทข้อ 3 ฉบับแรกใช้ภาษาความรู้สึกมากจนคำเชิญชวนขาดเนื้อหา จากนั้นทวนสถานที่เดิมจนภาพพะเยาแคบ ผู้ใช้ต้องช่วยดึงกลับไปสู่สถานที่และประสบการณ์ใหม่ การค้นหลักฐานก่อนร่างและแยกคำตอบตามหน้าที่ช่วยลดการวนซ้ำได้

## Lessons Learned

- **Pattern**: บทเสวนาหลายข้อควรแบ่งหน้าที่เป็นแนวคิด ตัวอย่าง และคำเชิญชวน เพื่อไม่ให้แต่ละคำตอบทวนกัน
- **Mistake**: อย่าใช้ภาษานามธรรมแทนตัวอย่างสถานที่และประสบการณ์ที่ผู้ฟังตัดสินใจใช้ได้
- **Discovery**: ส่งงานข้าม Oracle ต้องยืนยัน repository, delivery, การตอบ และหน้าต่างที่มองเห็นแยกกัน

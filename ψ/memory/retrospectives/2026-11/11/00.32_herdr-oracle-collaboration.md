## What Went Well

- ผู้ใช้ยืนยัน Lumina กลับมาผ่าน tmux และเปิด Oracle ทั้งสี่แท็บใน Herdr
- `herdr agent prompt` และ `agent read` จาก shell ส่งและอ่านคำตอบ Lumina จริง; no-daemon plus on-request ทดลอง prompt จาก Codex ได้หนึ่งครั้ง
- AIExpo MCP ตอบ list_lessons และ fetch บทเรียน; ร่างโพสต์จริงส่งและตอบผ่าน Codex messaging

## What Could Improve

- ยืนยัน transport และ pane เป้าหมายก่อนรายงานความสำเร็จ และแยกข้อความทดสอบจากงานจริง
- ลดการขอให้ผู้ใช้คัดลอกคำสั่ง พัฒนา workflow สั่งด้วยภาษาธรรมชาติหลังทดสอบสิทธิ์และความเสถียร
- ตรวจ context inheritance และ socket permissions เป็นคนละขั้นก่อนตัดสินว่าระบบพร้อม

## Blockers & Resolutions

- shell มี HERDR_ENV แต่เครื่องมือบาง Codex ไม่มี; process evidence แสดง shared daemon ไม่มี context; no-daemon ทำให้เครื่องมือทดลองเห็น context แต่ความคงเส้นคงวายข้ามเซสชันยังไม่ยืนยัน
- sandbox บล็อก Herdr socket; เซสชัน on-request ขออนุมัติและทดสอบสำเร็จ แต่บางเซสชันขอสิทธิ์ไม่ได้หรือไม่มี context; ห้ามปลอม marker และห้าม bypass sandbox
- ยังไม่ทดสอบ AXIOM/PRISM รับงานผ่าน Herdr ครบวงจร; tmux และ maw ยังไม่ถอน

## 💭 Honest Feedback

1. ผมให้ขั้นตอนที่ต้องสลับระหว่าง PowerShell, Bash, Codex และ Herdr หลายครั้งโดยไม่บอกให้ชัดว่าต้องพิมพ์ในช่องใด ส่งผลให้ข้อความธรรมชาติถูก shell แปลเป็นคำสั่ง ควรระบุหน้าจอและตัวบ่งชี้พร้อมข้อความแต่ละชนิดอย่างชัดเจน
2. ผมกล่าวว่าการส่งผ่าน Herdr สำเร็จหลังการทดลองหนึ่งครั้งเร็วเกินไป แม้การทดสอบนั้นสำเร็จจริง แต่ไม่ได้ยืนยันการส่งโจทย์จริงจากเซสชันเดียวกันต่อเนื่อง การตรวจ end-to-end ต้องระบุทั้งเซสชันและ transport และรอผลโจทย์ที่ต้องการ
3. ผู้ใช้ต้องการสั่ง Oracle ด้วยภาษาธรรมชาติ แต่ผมให้คำสั่งซ้ำและเสนอ channel อื่นซึ่งไม่ตรงเป้าหมาย การส่งผ่าน shell เป็นเพียงวิธีวินิจฉัย ไม่ควรถูกเสนอเป็นทางออกสุดท้ายโดยไม่บอกข้อจำกัดและภาระของผู้ใช้

## Lessons Learned

- **Pattern**: ตรวจ context ของ UI process, app-server และ subprocess แยกกัน รวมถึงสิทธิ์ socket
- **Mistake**: การทดสอบรหัสสำเร็จหนึ่งครั้งไม่ยืนยันว่างานจริงจะใช้เซสชันและ transport เดียวกันได้สม่ำเสมอ
- **Discovery**: Codex `--no-daemon -a on-request` ช่วยในการทดสอบ context และขออนุมัติได้ในเซสชันทดลอง แต่ไม่รับประกันทุกนโยบายหรือ session

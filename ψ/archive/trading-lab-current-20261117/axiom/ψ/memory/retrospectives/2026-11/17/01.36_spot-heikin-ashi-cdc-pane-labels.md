## What Went Well

- ยืนยัน Spot จากผู้ใช้ก่อนสรุป feed; มีตัวเลขรองรับการเลือก HA และแยกราคาเฉลี่ยจากราคาตลาด
- PRISM พบ REST/WS overwrite, ลิงก์ TF ที่ restore ไม่ตรง และ hover readout reset; แก้และทดสอบพฤติกรรมเฉพาะจุด
- Browser จริงพบ crosshair Value is null หลังวาดเส้นและเปลี่ยน TF; guard target ที่ว่างแก้ปัญหาได้
- เก็บ baseline/hash ก่อนแก้ทั้งสองงาน และทดสอบเส้นวาดจริงด้วยเมาส์ รวมการจำค่า/ปิด–เปิดป้าย/mobile

## What Could Improve

- ตรวจ mtime/hash และเปิด reference image ใหม่ทุกครั้งที่ผู้ใช้บอกบันทึกหรือเปลี่ยนแล้ว ก่อนทำงานตามภาพเดิม
- ทำรายการตรวจจาก Pine ให้ครอบคลุม plots, shapes, fills, label.new และ controls ไม่ตรวจแค่สูตรกับเส้น
- แยก log ของ canvas frame หลัง action ออกจาก frame ก่อน action; test แรกนับ frame ก่อนกดซ่อนเป็นความผิดพลาดของ renderer
- แยก intentional clicks จาก double-click gesture ใน browser test แทนเร่งคลิกจนกราฟตีความเป็นอีก gesture

## Blockers & Resolutions

- Layout ส่วนตัวเปิดจาก fresh browser ไม่ได้; ใช้ภาพและคำยืนยันแทน ไม่ล็อกอินหรือยืม credentials
- ไม่มี CSV บน plan ผู้ใช้; ไม่ยืนยันให้ upgrade และไม่ตั้ง CSV เป็นเงื่อนไขของกราฟที่ใช้งานได้
- Symbol/type ต่างจากข้อเสนอแรก; ผู้ใช้ยืนยัน Spot และตัวเลขพิสูจน์ HA ได้ตามความละเอียดภาพ
- Full all-bars/signals/6TF parity ยังไม่ยืนยัน; การยืนยันต่อจำเป็นต้องมี reference แท่งเวลาเดียวกันและ settings/history ที่ตรงกัน

## 💭 Honest Feedback

ความล่าช้าส่วนหนึ่งเกิดจากผมตรวจบริบทภาพใหม่ช้า และตรวจความครบของ visual output ไม่ครบในรุ่นแรก การผ่าน unit/browser ไม่ได้แปลว่าทำทุก object ของ Pine ครบ ต้องมี source-to-UI checklist และการทบทวนภาพควบคู่

ตรวจ metrics เดิมที่มีจริงทั้งหมด 2 แถว (น้อยกว่า7): friction ซ้ำคือ widget/custom Pine และการขาด TradingView reference/การพิสูจน์ parity งานนี้แก้ข้อจำกัด widget ด้วยกราฟของตนเองและภาพตัวอย่าง แต่ข้อจำกัด full parity ยังอยู่ ไม่เปิด issue อัตโนมัติ

## Lessons Learned

- Reference identity ต้องรวม exchange, Spot/Perpetual, symbol, timeframe, chart type, หน่วย/สกุลเงิน และ indicator settings
- Heikin Ashi เปลี่ยนทั้งแท่งและข้อมูลเข้า indicator; ถ้าแปลงเฉพาะหน้าตาแต่ใช้ raw OHLC คำนวณสัญญาณจะเทียบผิด
- Numerical match ของ snapshot, ความครบของ visual object และการตรวจทั้งประวัติเป็นหลักฐานคนละระดับ
- ป้ายล่าสุดต้องติดตามกราฟและเคารพ toggle เดิม; ข้อความนอก pane ไม่แทน label.new บน pane
- Session ID/เวลาเริ่มต้องมี attribution; inherited metadata ของ host ที่ไม่ชัดเจนให้เก็บ unknown

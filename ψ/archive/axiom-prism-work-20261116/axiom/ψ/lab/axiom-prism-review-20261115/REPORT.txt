ข้อบกพร่องที่พบและส่งกลับให้ PRISM แก้:
1. Import ตรวจ SHA256 แบบ async ระหว่างที่ยังเปิดสถานะได้ แล้ว overwrite สถานะใหม่ — แก้ busy ครอบคลุม file read/checksum/confirm และ recheck position ภายใน transaction; ทดสอบ race ผ่าน
2. Desktop-to-mobile resize ทำ chart/grid ล้น390px ไป906px — แก้ minmax(0,1fr), min-width:0; ทดสอบผ่าน
3. TradingView placeholder กินเต็มกรอบและ iframe ต่อท้ายถูก clip — แก้ container wrapper ภายใน outer fixed height; live BTC OHLC แสดงจริง
4. หุ้นไทย unsupported จริง — แสดงข้อจำกัดชัดเจนและลิงก์กราฟภายนอกตรง symbol
5. ชื่อรอบยาว200ตัว/บาง UUID ดัน account overflow — PRISM เพิ่ม overflow-wrap:anywhere; AXIOM ทดสอบ200ตัวผ่าน พร้อม PRISM layout metrics desktop1280/mobile390 ไม่ล้น
6. เพิ่มปฏิเสธ imported dataset ยังไม่ปิด/fetchedAt อนาคต; ตรวจ ledger และ checksum แยกกัน

ข้อจำกัดคงเหลือที่แสดงใน UI/export/README:
- ใช้ close ของแท่งที่เห็นและ fee สองด้าน เป็นแบบฝึก linear P&L; ไม่มี leverage/margin/liquidation/funding/slippage/orderbook/partial fill/SL/TP หรือ backtest อัตโนมัติ
- เก็บใน browser/origin เดียว ไม่มี cloud sync ใช้หนึ่งแท็บเป็นหลัก ส่งออก JSON สำรองภายนอก; localStorage มี quota
- SHA256 ไม่ใช่ลายเซ็นรับรองแหล่งข้อมูล; ต้องเชื่อถือ snapshot ต้นทางเอง
- รายการ legacy เก็บเดิมและแยกว่าไม่มี dataset/run context
- การเข้าถึง provider และความล่าช้าหุ้นไทยขึ้นกับผู้ให้บริการ เครือข่าย/ภูมิภาคอาจต่างกัน

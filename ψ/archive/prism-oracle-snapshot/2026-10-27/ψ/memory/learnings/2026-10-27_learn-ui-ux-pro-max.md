# Learned UI UX Pro Max

- แยกโจทย์ตามประเภทผลิตภัณฑ์ ผู้ใช้ บริบท และ stack ก่อนเลือกแนวทางออกแบบ; หลีกเลี่ยงการเดา stack
- ค้น design system สำหรับทิศทางภาพรวม หรือค้น domain/stack แบบเฉพาะเมื่อแก้ปัญหาจุดเดียว ตรวจว่าผลตรงบริบทก่อนนำไปใช้
- ให้ความสำคัญกับการเข้าถึง การตอบสนอง ฟอร์ม feedback และการแสดงข้อมูล โดยใช้ข้อเสนอเป็นจุดเริ่มต้นและตรวจผลจริง
- ข้อมูลโครงการและ design system เดิมควรรักษาไว้ การ persist/force มีผลเขียนไฟล์ ต้องตรวจบริบทก่อน

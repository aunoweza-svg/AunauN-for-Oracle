# REA: รูปแบบการทำงานและตัวอย่างจากซอร์ส

ศึกษา `morluto/rea` ที่ commit `0676ad254c206871e0f4b120ba300cbbf9383b62`; ตัวอย่างเป็นแนวทางจากซอร์ส ยังไม่ได้ติดตั้งหรือรัน REA

## ตรวจแอป JavaScript แบบ static

เอกสาร `README.md` และ `docs/cli.md` แสดงคำสั่งตัวอย่างดังนี้ โดยแทนที่พาธด้วยแอปที่มีสิทธิ์ตรวจ:

```powershell
npx -y rea-agents@latest analyze-javascript-application 'D:/apps/example' --json
```

คำสั่งนี้ตั้งใจวิเคราะห์ directory ของแอปที่แยกไฟล์แล้วหรือ ASAR โดยส่งคืน application graph และ Evidence; เอกสารระบุว่าผลเต็มอาจใหญ่มาก และมี `inspect-analysis-view` สำหรับดู summary หรือแบ่งหน้าข้อมูลจาก Evidence ที่บันทึกไว้ (`docs/cli.md`, หัวข้อ Run a command) ผลลัพธ์เป็นสิ่งที่เอกสารระบุ ไม่ใช่ผลการทดลองในเครื่องนี้

## หลักฐานแทนการเดาจากหน้าตา

`src/application/investigation/EvidenceLedger.ts` แสดงรูปแบบจัดเก็บ Evidence ใน session: `record` ตรวจความถูกต้องก่อนเก็บ หากรหัสเดิมมีข้อมูลตรงกันถือเป็น duplicate แต่ถ้าขัดแย้งจะคืนข้อผิดพลาด; `import` ตรวจ bundle และความขัดแย้งก่อนรวมข้อมูล รูปแบบนี้ช่วยรักษาที่มาและความสอดคล้องของผลวิเคราะห์

`docs/tool-design.md` ระบุให้แยกข้อมูลที่สังเกตได้ ข้อมูลที่อนุมาน และส่วนที่ยังไม่รู้ พร้อมบอก coverage และข้อจำกัด: การไม่มีหลักฐานเพียงพอไม่ใช่หลักฐานว่าไม่มีสิ่งนั้น PRISM นำหลักนี้ไปใช้ระบุหลักฐานและความไม่แน่นอนเมื่อวิเคราะห์ UI/UX ได้

## ตัวอย่างการสำรวจเว็บ

`docs/browser-observation.md` อธิบายการเชื่อม Chrome-family browser ที่ผู้ใช้เป็นเจ้าของผ่าน CDP; `inspect_web_page` เก็บข้อมูลหน้าและ `analyze_web_bundle` วิเคราะห์สคริปต์ที่เลือกแบบ static ส่วน `observe_web_session` เก็บเหตุการณ์ในช่วงที่ผู้ใช้ลงมือเอง การสังเกตหน้าเว็บที่เอกสารอธิบายเป็น passive ไม่ใช่ browser automation ทั่วไป; ความครอบคลุมขึ้นกับข้อมูลที่จับได้และข้อจำกัดที่รายงาน

## รูปแบบจัดการผลลัพธ์ขนาดใหญ่

`src/server/ToolResultDelivery.ts` แยกกรณีที่ผลวิเคราะห์ทำงานเสร็จแต่ response ใหญ่เกินงบ MCP ออกจากความล้มเหลวของการวิเคราะห์ และให้แนวทางกู้คืนแทนการถือว่าผลที่ถูกตัดทอนสมบูรณ์ สำหรับผู้ใช้ควรตรวจข้อความข้อจำกัดและใช้ summary หรือ view ที่เหมาะสม (`docs/cli.md`, `src/server/ToolResultDelivery.ts`)
